# Менеджер 3.6: вирівнювання SVG-іконок

Перевірено 2026-10-23 після заміни Font Awesome на Tabler.

## Зміни

- Базовий SVG трохи збільшено для компенсації внутрішніх полів Tabler; компоненти з фіксованими розмірами мають власні розміри.
- Верхнє меню використовує центровані слоти 20×20 px. Прибрані старі зсуви кнопки дерева й пошуку.
- Верхні вкладки мають спільний центр для іконки, підпису й закриття. Синя смуга активної вкладки більше не змінює висоту її вмісту. Внутрішні вкладки також центровані, включно з обгортками, які створює TabPane.
- Комірки списків елементів вирівняні по середині. Іконки дій мають розмір 16 px без старого внутрішнього padding; посилання мають фіксовану висоту.
- У списках ресурсів CSS masks та inline SVG мають однакові слоти 24×24 px із символом 16×16 px. Приватний замок не виходить за межі основної іконки.
- Замок у полі назви центрується flex-контейнером; збережені відкритий/закритий стани та червоний колір блокування.
- Малі кнопки та кнопки лише з іконками отримали явні розміри символів.
- На ширині до 840 px дерево закривається після переходу до ресурсу або вибору вкладки, зокрема на desktop browser. Повторний виклик не відкриває його назад; відновлення сесії саме по собі дерево не закриває.
- Marker CSS-кешу підвищено до v3: bundle попереднього вирівнювання перебудовується автоматично.

## Візуальна перевірка

Використано окрему локальну SQLite-інсталяцію. Основні дані сайту не змінювали; `core/vendor` основного checkout не відновлювали. Перевірки форм виконані без збереження.

| Екран | Перевірено |
|---|---|
| Верхнє меню та вкладки | Ширина 578 px; одна вісь усіх 11 видимих SVG, слоти 20×20 px. Іконки вкладок, підписи й хрестики мають однаковий центр |
| Дерево у вузькому менеджері | Перехід до ресурсу та вибір відновленої вкладки закривають drawer; робоча область починається з x=0 |
| Шаблони | Рядок, опис, іконка назви, редагування/копіювання/видалення; на 1280 px різниця центрів іконки назви й дій менша за 0.1 px |
| Плагіни | Чотири рядки, включно з вимкненням; центри назви й усіх дій збігаються |
| Модулі | Список у Elements та окремий Manage Modules; запуск, редагування, вимкнення, дублювання, видалення |
| Користувачі та ролі | Іконки рядків, пошук/скидання, New User, контекстне меню, вкладки ролей |
| Дочірні ресурси | Приватний документ, badge замка, чотири дії рядка, заголовок і верхній toolbar |
| Редактор ресурсу | General/Settings, вузький toolbar збереження, іконки біля полів і вибору батьківського ресурсу |
| Редактор шаблону | Центр замка в полі назви, обидва стани; зміщення центру 0 px |
| Налаштування | Site, Interface & Features, File Manager; вкладки, заголовок і toolbar |

Сторінки списків і налаштувань також переглянуто на ширині 1280 px. Це перевірка штатних екранів і тестових записів, а не сторонніх Extras або всіх можливих наборів даних.

## Автоматичні перевірки

- 209 Pest-тестів / 2107 assertions: Manager і CSSMinify.
- 102 Node-тести: менеджер і файловий браузер; нові сценарії drawer на 480, 746, 840 та 841 px, повторного закриття й відновлення сесії.
- PHPStan: без помилок.
- PHP/JavaScript syntax, повторна генерація 152 SVG masks та `git diff --check`: без помилок.

Font Awesome, aliases і legacy fallbacks не додавалися.
