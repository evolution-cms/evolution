# Evolution CMS 3.6 — заміна Font Awesome

Реалізовано в `3.6.x`, 2026-10-23. Початкові таблиці у [FONT-AWESOME-MIGRATION.md](FONT-AWESOME-MIGRATION.md) і [HTML-каталозі](ICON-CATALOG.html) зберігають знімок використань **до** заміни; номери рядків у поточному коді можуть зміститися.

## Що змінилося

- Видалено весь Font Awesome: спільний CSS, 15 спільних шрифтів і 15 дубльованих шрифтів теми. Старих URL, класових aliases і fallback-шарів немає. Старі Extras мають перейти на Evo UI окремо; їхні репозиторії не змінювали.
- Погоджені Tabler SVG використовуються в меню, інструментах, списках, повідомленнях, календарі, модулях ядра, перекладах, менеджері категорій і файловому браузері.
- Чинні Blade `svg('tabler-*')` залишені. Для класових значень `$_style`, вставок JavaScript та CSS-псевдоелементів ті самі SVG упаковані у CSS masks: кольори успадковуються від `currentColor`, додаткового JS або шрифтів не потрібно.
- `evo-icon evo-icon-<назва>` — класовий контракт для цих SVG. Розмір, обертання, fixed width і композиція мають відповідні `evo-icon-*` утиліти. Завантаження враховує `prefers-reduced-motion`.
- CSS-кеш отримав новий version marker: старий bundle із Font Awesome перебудовується. Відносні URL зображень перераховуються для об’єднаного CSS; за відсутності writable-кешу завантажується вихідний stylesheet.
- Видалено невикористані EasyUI, FileAPI, jEditable, euigrid, euiuploader та Handlebars. JPEG входу зменшено до 1920×1080 / 286,649 байтів зі збереженням JPEG.

## Стани дерева

| Стан | Відображення / поведінка |
|---|---|
| Порожній кошик | `tabler-trash`, disabled, `aria-disabled=true`, клік очищення відсутній |
| Повний кошик | `tabler-trash-filled`, активний, `aria-disabled=false`, збережена дія очищення |
| Закрита папка | `folder`, caret right |
| Відкрита папка | `folder-open`, caret down; після AJAX і повторного закриття стан зберігається |
| Приватна папка / документ | Окремий червоний `lock` у куті; не зникає при заміні основної іконки |
| Блокування редагування | Окремий замок / eye та наявна дія розблокування |
| Weblink | Основна іконка документа з окремим `link` біля назви |
| Deleted / unpublished / hidden | Існуючі класи, перекреслення та кольори статусів збережені |

## Збірка іконок

Джерело: locked `secondnetwork/blade-tabler-icons` v3.49.0, commit `d219634a7948627ebf861012ca798573c2ad2aa3`.

```sh
# Після встановлення залежностей core; звичайна робота CMS не потребує запуску генератора.
php tools/build-manager-icons.php
```

Перелік: `manager/media/style/common/icons/icons.json`. Згенеровано **152** символи, потрібні класовому UI та CSS-псевдоелементам ядра. `manager-icons.css`: **131,189 байтів**. Зміна пакета потребує повторної генерації. MIT-ліцензія збережена поруч. Генератор не вимагає bootstrap CMS.

## Перевірки

- **209 Pest-тестів / 2106 assertions**: менеджер, SVG-ресурси, CSS-кеш і перерахунок URL.
- **97 Node-тестів**: менеджер та файловий браузер, включно з відкриттям/закриттям приватної папки і full/empty кошиком.
- `composer analyze`: **No errors**; PHP syntax та `git diff --check` без помилок.
- Окрема повна SQLite-інсталяція з залежностями поза основним checkout: логін, сторінка налаштувань, дерево документів, відкрита/закрита приватна папка, badge замка, full/empty кошик. На перевіреному екрані не залишилося FA-класів; SVG masks завантажені.
- Основний локальний `core/vendor` не відновлювали. Перевірка не змінює основну базу даних.

HTML/PDF містять історичні зразки Font Awesome для порівняння зі старими іконками. Ці автономні документи не підключаються до runtime менеджера. Старі записи класів у сторонніх Extras і користувацькому контенті БД навмисно не адаптуються.
