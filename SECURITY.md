**Security Policy**

Security vulnerabilities are promptly addressed by the Evolution CMS core team in the current nightly development branch.

As an open-source project, our development branch is publicly accessible, including security fixes. However, we ask that you contact the core team before publicly disclosing vulnerabilities so we can assess their severity and determine whether an expedited security release is necessary, potentially bundling multiple fixes.

To report a security vulnerability, follow the instructions at https://evo.im/.well-known/security.txt.
